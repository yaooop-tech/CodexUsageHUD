# Codex Usage HUD v1.8.4

## Highlights

- Restored hover auto-collapse after the pointer leaves the expanded HUD, including while Codex, Claude, or Kimi task activity is visible.
- Kept activity indicators and unread completion reminders intact when the HUD returns to its collapsed rail.
- Bumped the app bundle to version 1.8.4 (build 12).

## Notes

- Apple Silicon only; requires macOS 14 or later.
- This preview remains ad-hoc signed and not notarized. See the README for first-launch Gatekeeper steps.
- The ZIP includes only the app and required helper. A SHA-256 checksum is provided alongside the download.
