# Codex Usage HUD v1.8.2

## Highlights

- Fixed the collapsed dual-window activity layout: a running task with completed reminders now always uses the compact `THK` label, so the status capsule stays inside the HUD.
- Centered the active 5-hour and weekly metrics, and increased the vertical separation before the weekly metric while work is running.
- Refined the expanded Codex layout: 5-hour and weekly windows no longer use rounded card backgrounds, use the same typography as the weekly-only view, and fit inside a fixed, non-scrolling window.

## Notes

- Apple Silicon only; requires macOS 14 or later.
- This preview remains unsigned and not notarized. See the README for first-launch Gatekeeper steps.
- The ZIP includes only the app and required helper. SHA-256 is provided alongside the download.
